\section{Conclusion}\label{sec:conclusion}
Integrating platforms into a fixed reference changes which methods work: a spatially aware joint method transfers
labels worse than no alignment here and rebuilds the reference it was asked to serve. \frost keeps the reference
fixed and transfers labels better than, or not significantly differently from, every external baseline. In batch
mixing against label transfer it sits with USHER-CC, the two indistinguishable, well apart from no alignment,
Harmony and Scanorama (Figure~\ref{fig:pareto}) and from GraphST (Table~\ref{tab:graphst}). It does so with 25-fold fewer
structure computations than the algorithm it builds on at that algorithm's 25 EM iterations (a $T$-fold reduction
for $T$ iterations); gene-level information remains outside the reach of
embedding alignment.

\section*{Code and data availability}

\noindent\textbf{Code.} All code supporting this study will be released at
\url{https://github.com/Hepha4438/frost} and archived with a DOI on Zenodo upon publication.
The release comprises (i) the alignment pipeline and all baseline wrappers, (ii) the
evaluation and statistics code for every metric reported here, (iii) the figure scripts
together with the derived data files they read, and (iv) pinned dependency specifications
for the three environments used (main benchmark, spatial baseline, and the isolated
environment required by \texttt{symphonypy}).

\noindent\textbf{Modifications to third-party code.} \frost is built on the USHER reference
implementation~\citep{pratapa2025usher}. Our changes to that code base are distributed as patches
against the upstream repository rather than as a redistributed copy, so that every
difference from the published implementation is explicit and auditable. The scope of reproducibility from the
release is described in Supplementary Section~S3.

\noindent\textbf{Data.} This study uses the SPATCH resource~\citep{ren2025spatch}
(\url{https://spatch.pku-genomics.org}), which provides matched Xenium 5K, CosMx 6K,
Visium HD and Stereo-seq profiles of colon adenocarcinoma, hepatocellular carcinoma and
ovarian cancer. No new data were generated. We redistribute no primary data; the release
includes a download script that retrieves the required sections from the SPATCH portal.
